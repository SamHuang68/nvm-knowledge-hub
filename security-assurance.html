01 / PHYSICAL ATTACK SURFACE

觀察、擾動、讀取：三種不同的證據問題

攻擊類別不是產品恐懼清單；它們用來建立可測試的安全需求。

OBSERVE

Side-Channel Analysis

量測 power、EM、timing 或 contactless emission，判斷 PUF reconstruction、key derivation 與 AES access 是否洩漏可利用資訊。

ASSETSPUF response · root/derived key · plaintext window
DISTURB

Fault Injection

以 voltage、clock、EM 或 laser fault 挑戰 authentication、lifecycle state、program flow、crypto 與 zeroization。

OUTCOMEScheck bypass · DFA · state corruption · oracle
READ

Invasive Analysis

直接觀察 OTP cell、routing 或殘留狀態。安全目標不是假設讀不到，而是讓讀取結果不足以還原可用的 root secret。

BOUNDARYciphertext · scrambling · helper data · layout
