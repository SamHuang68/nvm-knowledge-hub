## 圖與動畫的設計契約

- 首頁 A／B 表示兩個可區分狀態，不指定所有產品通用的 0／1，也不模擬產品性能。四個機制與原首頁索引共用同一資料及既有專題路由。
- 工程步進投影原始狀態 SVG，保留完整並排圖、來源、圖例與原錨點；不插入未經來源支持的物理中間態。播放器只處理閱讀次序。
- 生命週期圖區分 OTP 密文、helper 資料與中繼資料的持久存在，及重建金鑰／明文的暫存路徑。零化是驗證目標，圖面不宣稱實體操作已完成。
- 手動前後、播放／暫停與重設可用鍵盤操作；減少動態偏好仍可手動閱讀。沒有 JavaScript、列印或明示 `motion=static` 時保留完整靜態圖面。
- 搜尋分類、ARIA 狀態、焦點與非同步總帳重試沿用原控制器。新增按鈕已納入焦點順序，沒有建立第二份搜尋資料或效能模型。

## 根因、防再發與獨立審查

工程圖白色磁矩在共用重塗後對 `#e2e8f0` 的對比為 1.23:1。修正來源層後，對自由層／參考層為 4.84:1／6.78:1；P／AP 及 Vread 為 12.46:1／5.25:1。下載 SVG 內嵌實際樣式，避免離開網站後再度失色。

PUF 的既有近似 `k=128−7t` 在 t≥19 非正。原 t=6–22 輸入全部保留，超出定義域時呈現「超出此簡化模型」，不產生負容量或無效熵。

獨立唯讀程式審查找出工程演示的 `checkVisibility()` 無法判斷 viewport 外，以及探針 group 按鈕的初始 `aria-pressed` 與動態 `aria-selected` 不一致。前者以實際捲動重現後補上 `IntersectionObserver`，新增六個中英尺寸案例；後者統一為 `aria-pressed`，新增五情境按下狀態與可解析標籤的瀏覽器斷言。

本輪 AGENTS.md 明示新檔名採臺灣繁體中文，與舊 ASCII 命名檢查衝突。發布政策新增具有指示依據的精確來源路徑例外，僅接受存在且位於儲存庫內的 CSS、JavaScript 或 Markdown 檔；未列名路徑仍拒絕，附件與公開分類限制照原契約驗證。

## 驗證範圍與限制

執行 `npm run build`、`npm run check:content`、必要來源紀錄檢查，以及相關瀏覽器回歸；沒有執行完整全站回歸套件。測試日誌與畫面留於本工作樹 `qa/`，不納入公開資源或版本提交。

實際瀏覽器涵蓋桌機 1440px、手機 390／320px、中英文、鍵盤、靜態／列印／減少動態偏好、下載 SVG、真正捲動離開畫面與離線升版。未宣稱 Firefox、WebKit、人工讀屏或原生背景頁籤全部驗收。模型生命週期中的頁籤隱藏分支只取得明確標記的事件模擬；其餘十二項為實際畫面、元件及互動驗證。

模型係數仍是教學假設，尚未以具名製程量測校正。V20 的逐項引用、公式與輸入仍是可見的證據缺口。本次不把文字修訂日期當成新的外部來源查核日期。

圖鑑持續使用既有 SVG 延遲實體化與離線契約。完整 HTML 仍含全部原始圖面；本次沒有量測或宣稱公開服務的網路傳輸與 Core Web Vitals 改善。效能成果限於已驗證的動畫排程與停止行為。
