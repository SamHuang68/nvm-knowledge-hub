## 2026-10-14／v1.5.4／執行鎖保全與獨立恢復

基準：8dda320f6b26c745c578d06d9aa0bbad6835b9ad。已重現原程序在鎖內容被替換後仍寫入成功並刪除替換鎖；修正為寫入報告、移存舊結果及釋放鎖前核對檔案身分、runId 與 PID。檔案身分或內容不符就停止，不以 PID 是否存活推測鎖可刪除。

既有入口新增 `--recover-output --asset=相對路徑`：在指定輸出目錄下建立「恢復-本次識別」獨立目錄，產生新鎖與新報告，保留原目錄的執行鎖及所有結果。即使原程序仍在執行也不修改它的資料；不複製舊成功、不續用舊 runId。未明列資源或重複指定恢復選項會失敗，零個網路請求，不啟動完整掃描。

報告須對照啟動紀錄的實際輸出路徑與 runId，確認 state=通過、passed=true、finishedAt 及成功退出。恢復不代表原執行已完成，也不自動整理或刪除歷史檔；沒有寫入權限仍可能無法產生新報告，退出碼與訊息維持失敗。

Windows 局部十案通過：首批九案，加上後續鎖檔實體替換一案；涵蓋實際子程序強制中斷與原程序仍在執行。原 HTTP 判讀、正規化與離線區塊未修改，沿用既有證據。CI 明列相同十案、力旺統計四畫面與產物保全，不執行完整測試套件。狀態：本機已驗證候選；提交及發布以同次交付紀錄追溯。

## 2026-10-14／v1.5.3 驗證修訂 4／正式來源驗證生命週期

基準：0a8d404e94ba938d639b11e39ed799b17b5f4d40。已重現程序強制終止後仍留下舊成功報告、同目錄兩程序同時發出請求，以及報告不可寫卻先開始網路驗證的缺口。

- 連線前先取得同目錄獨占執行鎖，移存舊報告為明確命名的歷史檔，寫入本次 runId、PID、執行中狀態及 passed=false；完成報告用同目錄暫存檔、fsync 與原子替換，避免半份 JSON 被當成結果。
- SIGINT／SIGTERM 處理器及未預期退出保存已中斷狀態；無法攔截的強制終止保留未完成報告與鎖，不自動猜測程序歸屬或清除殘留鎖。重試先確認原程序，或明確指定新的輸出目錄。
- 同目錄並行執行在連線前拒絕，且不覆寫原執行結果。正常成功或失敗會釋放自己的鎖；循序重跑使用新識別，保留前次歷史報告。
- 初始報告無法寫入即停止，完成報告寫入或替換失敗不宣告成功。若檔案系統連舊報告移存都拒絕，舊檔確實無法更新；程序以非零退出及本次識別明示舊報告不得視為本次證據。既有報告路徑若是資料夾或符號連結，直接拒絕，不移動其中資料。

判讀方式：同時核對本次啟動紀錄的 runId、報告 state=通過、passed=true 與成功退出；歷史檔或執行中報告不是本次完成證據。不要把單獨一個舊 passed=true 當成新執行成功。

Windows 局部驗證：首批十案通過，後續只補舊報告移存失敗、部分寫入及資料夾保全三案，均通過。寫入失敗採程序內檔案系統故障注入，沒有實際填滿磁碟；強制終止是實際子程序中斷。Windows 訊號案例驗證處理器，Linux CI 使用真實 SIGTERM。CI 明列十三案及產物保全，不啟動網站瀏覽器或重跑完整 HTTP／產品套件。

狀態：本機已驗證候選；提交與發布由同次交付紀錄及來源識別追溯。產品仍為 v1.5.3；原 HTTP 判讀、內容正規化與離線流程未修改，沿用相關有效證據。沒有重新執行完整離線流程，也沒有製造正式網站故障。

## 2026-10-14／v1.5.3 驗證修訂 3／正式來源錯誤處理與局部模式

基準：34bf166cf2f18e930fdcd82e136c5cfd9d88d278。以原入口及本機 HTTP 夾具重現三項缺口：跨來源重新導向回傳相同內容會誤判通過；一筆傳輸失敗會讓同批逐檔結果遺失；無效選取在報告寫入前退出，留下同一目錄中的舊成功報告。

- 改為明確處理重新導向，保留同來源正常導向及內容比對；記錄起點、實際回應網址與導向鏈。跨來源不發出後續請求，缺少位置或超過五次導向均失敗。
- 單筆請求的 30 秒上限涵蓋標頭、導向及完整內文；`NVM_QA_TIMEOUT_MS` 只可設定 1 至 30000 毫秒以縮短等待，無效設定在連線前拒絕。逾時、傳輸中斷、HTTP 錯誤、403／1010 與內容不一致分開記錄，仍以非零退出碼失敗。
- 每筆資源自行保存結果，同批成功紀錄不因另一筆失敗而遺失。參數、基底與資源驗證移入結果寫入範圍，錯誤會覆寫舊成功報告，沒有退回完整流程的分支。
- 未指定參數的原有完整清單與離線流程保留；有參數只接受明列 `--asset=`，局部模式不啟動瀏覽器。原有 BOM／CRLF 正規化及內容雜湊不變。

本機驗證：原版本三個負向案例均揭露上述問題，修正後十九個 HTTP 契約案例通過。第一次新增導向夾具的中文 Location 未編碼而中止，改用網址編碼後通過；失敗證據保留，沒有降低斷言。CI 只執行受影響 HTTP 案例及既有產物保全，其他產品互動證據沿用。

狀態：本機已驗證候選；提交與發布狀態由同次交付紀錄及 `data/release-lineage.json` 追溯。產品版本仍為 v1.5.3；本次未重跑完整離線流程，未變更 Cloudflare 設定或網站功能。
