## 2026-10-13 · v1.4.1 · 查閱改善候選

基準：9011ec36c84035f4e418be1b58b9391c2f5a4efe（v1.4.0）；維持 12 家廠商、19 個技術組合、57 筆收錄與 53 個不同公報。

原因：閱讀案卷後修改篩選，網址可能仍指向已被隱藏的舊案卷；重新整理因此清空新篩選。矩陣連結另有將舊查詢參數凍結在絕對網址的同類問題。已先用原失敗流程重現，再修正來源。

- 新增廠商／IP 沿革精確篩選，與關鍵字、技術及收錄狀態取交集；全文搜尋仍能找到正文提及其他公司的內容。
- 在每筆公報案卷新增返回入口：有篩選結果時返回公報結果，其他情況返回地圖搜尋；沿用既有焦點與歷史路由，無 JavaScript 時仍可返回可見總覽。
- 使用者修改篩選後，僅將已失效的案卷錨點正規化為搜尋入口；外部直接案卷連結仍優先揭露。矩陣與返回連結使用相對片段，避免舊查詢參數覆蓋目前篩選。
- 所有研究原文、來源、案卷與既有錨點保留，不新增資料來源或依賴。控制列改為搜尋加三個分類欄位，窄螢幕廠商欄保持全寬。

驗證範圍：既有專利地圖局部案例加入廠商交集、矩陣跳轉、返回結果、重整與語系／歷史狀態；沿用 Chromium／WebKit 模擬、雙語桌面／手機及無 JavaScript 閱讀，不跑完整掃描。Chromium／WebKit 各四組局部情境均通過（含原失敗流程）；原始失敗與修復收據存於本次交付紀錄。

發布身分：提交後由 data/release-lineage.json 綁定完整內容 SHA；本機提交、PR、CI 與兩站發布結果記錄於 v1.4.1 交付紀錄。法律狀態與 FTO 仍是收錄研究，未新增逐案法律查證聲明。
