HOW TO USE THIS REFERENCE如何使用這個知識中心

Keep the Evidence with the Engineering Decision由原理到選擇，每一步都保留證據

  1. 01

    Separate Physics and Architecture辨別物理與架構

    Start with the stored variable and operation, then account for array and system costs.先看儲存變數與操作，再確認陣列與系統的代價。

  2. 02

    Check a Named Implementation核對具名實作

    Bind speed, endurance, retention, and production status to the same implementation and conditions.速度、耐久、保持與量產，必須綁定相同產品及條件。

  3. 03

    Reuse the Content with Its Sources保留來源再重用

    Download the English or Chinese study data as a shared source for presentations and teaching.中英文資料可下載，作為後續簡報或教材的共同來源。
