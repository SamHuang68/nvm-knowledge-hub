MODULE 01 OF 07 :: SECURE STORAGE ARCHITECTURE
KEY RESIDENCY: EPHEMERAL · SHUTDOWN ASSURANCE
機密長存 · 根金鑰瞬態 Persistent Data · Ephemeral Root

永久保存機密資料，
根金鑰不永久留存於晶片介質 Keep data permanent—
not the root key on silicon medium

以 SRAM PUF 於每次上電依物理失配重構 Device-Unique Root Key，搭配硬體 AES-256 即時加解密 AntiFuse OTP。下電後不存在已重建的根金鑰，將物理探針與故障注入攻擊限制在無意義的加密密文區間。 Reconstructs device-unique root keys dynamically via SRAM PUF mismatch at power-up, paired with hardware AES-256 real-time crypto over AntiFuse OTP. No reconstructed root exists at power-off, confining physical probes and fault injection to meaningless ciphertext.
