# 白皮書建置與驗證

`src/data/nvm_specs.js` 是 12 筆選型資料的唯一來源；`src/js/modules/` 同時提供瀏覽器與靜態預先渲染。正式入口的外框在 `公開入口樣板.html.tpl`，正式樣式在 `src/styles/正式樣式.css`，語系在 `src/js/白皮書語系.js`。正式樣式保留既有部署版本的主題與排版修正。

`whitepaper/` 下的 `index.html`、`assets/白皮書.js`、`assets/白皮書.css`、`assets/whitepaper_i18n.js` 與 `建置清單.json` 均為建置產物，請修改來源後重建。原有帶雜湊檔名的舊資源保留供既有頁面快取過渡，新的入口不再引用。舊 `main.css`、`components.css`、`portal.css` 不在正式依賴圖中；請勿將新樣式寫入這三份歷史來源。

次入口 `tools/whitepaper-studio/index.html` 會保留查詢參數與章節，導向同一個正式入口；不再執行另一組來源模組。沒有 JavaScript 時提供正式白皮書與主站連結。

在專案根目錄執行：

```powershell
npm ci --prefix tools/whitepaper-studio
node scripts/建立白皮書.mjs
node scripts/驗證白皮書一致性.mjs
npm test --prefix tools/whitepaper-studio
npm run check --prefix tools/whitepaper-studio
```

一致性檢查在記憶體重新建置並比較來源雜湊、12 筆紀錄 ID、資料雜湊及正式產物，文字統一使用 LF。此檢查不會覆寫失同步的產物。

瀏覽器檢查需要先由專案根目錄執行 `npm run serve`，接著執行 `npm run qa:render --prefix tools/whitepaper-studio`。預設使用 `http://127.0.0.1:8765`；`NVM_QA_BASE` 或 `WHITEPAPER_QA_URL` 可指定已啟動的本機網址。Windows 預設使用 Edge，其他系統使用已安裝的 Playwright Chromium；`NVM_QA_BROWSER=chromium` 可指定 Playwright 管理的 Chromium。結果與截圖輸出到不受版本控制的 `qa/白皮書驗證/`。

公開內容查核允許有指定官方來源及欄位範圍的 NeoMTP 描述；URL、程式碼與版本參數不當成公開聲稱。所有原稿數值與認證文字均保留，逐筆標示待查證範圍。來源只支援明列的欄位，不代表認證、量產或完整產品規格已獲證明。
