選型指南 Decision Flow Decision Flow Guidelines

01

需要多次覆寫嗎？Need Multiple Rewrites?

是 ➔ 考慮 eFlash (若製程 ≥ 28nm) 或 eMRAM/eRRAM (若製程 < 28nm)。
否 ➔ 進入下一步。 Yes ➔ Consider eFlash (if node ≥ 28nm) or eMRAM/eRRAM (if node < 28nm).
No ➔ Proceed to next step.

02

是否在意光罩成本 (Mask Adders)？Sensitive to Mask Adders?

是 ➔ 選擇 Logic NVM (AntiFuse OTP / eFuse)，不增加額外光罩。
否 ➔ 進入下一步。 Yes ➔ Choose Logic NVM (AntiFuse OTP / eFuse) for zero mask adders.
No ➔ Proceed to next step.

03

高安全性與先進製程微縮？High Security & Advanced Scaling?

要求高防篡改能力或使用 16nm 以下製程 ➔ 首選 AntiFuse OTP。
僅需基礎修補且面積不敏感 ➔ 可用傳統 eFuse。 Requires high anti-tamper or sub-16nm nodes ➔ AntiFuse OTP is preferred.
Basic trimming without area constraints ➔ Traditional eFuse.
